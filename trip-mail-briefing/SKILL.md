# trip-mail-briefing — 출장 저녁 메일 브리핑

폴더 안 하루치 수신 메일을 분류하고 옵시디언 볼트 맥락과 결합해 **🔴 급함 / 🟡 해야 할 일 / ⚪ 참고** 브리핑을 만든다. 🔴는 회신 초안까지. 설계 원본: `{mail}\00_가이드\출장브리핑-스킬-설계.md`.

## 경로
`%USERPROFILE%\.claude\skills\_config\local-paths.md`에서 `{vault}`·`{mail}` 로드. 스크립트는 `%USERPROFILE%\.claude\skills\mail-bridge\scripts\`.

## 절차 (전부 python — ⚠️ Outlook COM 절대 사용 금지, S/MIME 메일에서 무한 행)

1. **인덱스**: `python extract_msg_headers.py --folder "<폴더>" --out "<폴더>\_headers.txt"`
2. **노이즈 필터**: `{mail}\00_가이드\패턴.md`의 필터링 규칙(광고·뉴스레터·부재 자동응답·회의 자동수락 "Accepted:"·사내공지·사교). 걸러낸 것은 버리지 말고 **제외 목록(건수+제목)**으로 브리핑 말미에 첨부. 애매하면 남긴다.
3. **본문 추출**: 남은 id 전부 `python extract_msg_by_id.py --headers ... --base "<폴더>" --ids "..." --maxbody 2000 --out ...`
4. **볼트 맥락**: 발신자 → `{vault}\20. Contacts` (description·Remarks), 안건 키워드 → 프로젝트 MOC·`{mail}\01_케이스\_교차매칭\_triage.txt` grep → **스레드가 어디까지 와 있는지 한 줄**. 볼트에 없으면 "신규 안건" 표시.
5. **분류** (안건별 묶음):
   - 🔴 **급함**(오늘~내일 회신): 예준님 직접 To+질문/요청 · 마감 명시("本日中" 등) · 고객/대리점(WNC·TEXTECH·임예하·김정동·고재환 등 매핑표 인물) 발신 · 상대가 회신 대기 중 · **당일~익일 회의/일정 포함 메일**(Teams 링크·시각 명시)
   - 🟡 **해야 할 일**(이번 주): 액션 필요하나 즉답 불요
   - ⚪ **참고**: FYI·CC만·진행 통지 — 단 **CC라도 당일 액션·중대 안건이면 상향**
   - 판단이 애매하면 **급한 쪽으로 상향** (놓치는 것보다 과보고)
6. **🔴만 초안**: mail-bridge 모드 A 규칙(`패턴.md`+`02_매핑\연락처-매핑.md`)으로 회신 초안 2벌 — 예준님 확인용 KR + 발송용 상대언어. To/CC/스레드 명시. 발송은 예준님.
7. **출처 표기 (🔴🟡⚪ 전 항목 필수)**: 모든 항목에 **발신자 + 메일 제목(원문 그대로)**을 적는다 — 예준님이 Outlook에서 바로 검색해 원본을 찾을 수 있어야 한다. 🔴뿐 아니라 🟡·⚪도 예외 없음. 한 항목이 여러 메일을 묶었으면 **묶은 메일을 전부 나열**(발신자 + 제목 + 시각). 요약·의역한 제목은 금지, 원문 SUBJ를 그대로.
8. **근거 구분**: 메일 본문에 없는 내용(볼트·기억·추론에서 끌어온 것)을 액션으로 적지 않는다. 붙이려면 "메일 근거 없음 · 확인 필요"로 명시. 액션 줄에는 **그 메일이 실제로 요구하는 것만**.
9. **출력 두 벌**:
   - 채팅: 개조식 브리핑 (🔴부터, 항목당 발신자·제목 + 요지 1줄 + 볼트 맥락 1줄 + 제안 액션 1줄)
   - HTML: `<폴더>\YYMMDD_저녁브리핑.html` — **생성 전에 primetals-text-style 스킬을 로드**해 브랜드 팔레트·폰트 적용(다크블루 배너+오렌지 룰, 긴급도 배지 Red/Orange/Grey), 자기완결 단일 파일, 🔴 초안 전문 포함. 각 항목 머리에 `발신 / 제목` 행을 둔다. 볼트에 저장하지 않는다.

## 실패 처리
- 읽기 실패: 건너뛰지 말고 "미판독 N건(파일명)" 명시
- 메일 0통/폴더 없음: 즉시 보고하고 종료
- 초안 근거(스레드·담당자) 불확실: 지어내지 말고 "미확인" 표시 — 판단은 예준님

## 관련
- 라우팅·작문 규칙: mail-bridge 스킬 (지식 소스 동일)
- 노이즈 필터·케이스 로그: `{mail}\00_가이드\패턴.md`
