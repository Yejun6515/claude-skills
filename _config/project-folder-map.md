## 스킬이 지켜야 할 것

1. **새 노트·새 폴더를 만들거나 프로젝트 자료를 찾을 때, 탐색하지 말고 위 절의 표에서 볼트 경로와 U: 경로를 동시에 얻는다.** 볼트 전체 Grep·U: 전체 탐색 금지
2. 표에 **없는 프로젝트는 지어내지 말고 예준님께 확인**한다. 확인되면 **볼트 노트의 표에 한 줄 추가**한다(이 파일이 아니라)
3. 폴더 규칙(3계층 · 케이스 `YYMMDD_주제` · `_attachments\<메일번호>__<파일명>` · `submission\` · HTML은 U:에 두고 노트엔 `file:///` 링크)도 같은 절에 있다
4. 노트를 만들면 `# Yejun's memo`에 **소스 폴더 `file:///` 바로가기**를 반드시 단다 — 표는 이 링크들에서 재도출되므로, 링크를 빠뜨리면 표가 늙는다
