# jp-drama-word-tts (드라마 단어 TTS 워크플로우)

LLN 드라마 파이프라인의 **단어 학습 구간**을 담당한다. 전제: 해당 화 폴더에
`{제목}_분석완성.xlsx`(A번호·B단어분석·C원문·D번역)가 이미 있다(jp-drama-excel 산출물).

## 전체 흐름

```
1. 피커 생성   : build_picker.py → 단어피커_{제목}.html (사용자에게 열어서 고르라고 안내)
2. 사용자 선택 : 피커에서 클릭 → [선택 목록 복사] → 채팅에 "단어1, 단어2, ..." 붙여넣음
3. 대사 매핑   : extract_word_lines.py → _word_lines.json (단어별 원문 대사·번역·읽기·뜻)
4. 대본 작성   : Claude가 단어마다 2종 작성 → {화폴더}\TTS\대본\
                 "N. 単語_대본.txt"(한자, 눈용) + "N. 単語_대본tts.txt"(히라가나, TTS용)
5. 배치 실행   : run_tts_batch.py → {화폴더}\TTS\N. 単語.mp3 (번호 = 피커 선택 순서)
6. 단어정리 txt: Claude가 {화폴더}\TTS\{제목}_단어정리.txt 작성 (글라스용, 아래 양식)
7. 단어장 기록 : record_vocab.py → 볼트 15.10. 일본어\_tts단어장.csv (다음 화 피커에서 회색 처리)
8. 정리        : {제목}_대사단어_글라스.txt(jp-smartglass-vocab 산출물)를 media 폴더로 이동,
                 media 폴더의 jpg(장면 캡처) 전부 삭제. 탐색기로 TTS 폴더 열어 안내.
```

## 스크립트 사용법

```
python scripts\build_picker.py        "<화 폴더>" <제목>
python scripts\extract_word_lines.py  "<화 폴더>" <제목> <단어목록.txt>
python scripts\run_tts_batch.py       "<화 폴더>"          (백그라운드 권장, 재실행 시 이어하기)
python scripts\record_vocab.py        "<화 폴더>" <제목> "<출처 라벨>" <YYYY-MM-DD>
```

- **한글 경로 주의**: 파이썬 코드를 stdin 파이프로 넘기면 인코딩이 깨진다. 반드시 .py 파일로
  저장해 실행하고 `PYTHONIOENCODING=utf-8` 설정.
- 출력 폴더는 **항상 작업 중인 화 폴더 안** (`TTS\` 하위 폴더). 고정 경로 사용 금지(예준님 지시).

## 대본 작성 규칙 (word-tts 스킬 준수 + 추가 규칙)

기본 규칙(히라가나 인라인, 한자 분석은 한국 훈음으로, 숫자 한글, `<break time="0.3s" />`,
복합동사 분해)은 **word-tts SKILL.md**를 따른다. 이 워크플로우의 추가 규칙:

1. **예문 첫째 = 실제 드라마 대사.** `_word_lines.json`에서 가장 짧고 명확한 대사를 골라
   히라가나로 변환, 대본에 "첫째, 드라마에 나온 문장이에요."로 표시. 긴 대사는 해당 구절만 발췌.
   예문 둘째·셋째는 창작.
2. **기본형+가능형 등 같은 동사의 변형이 함께 선택되면 하나로 병합**하고 대본 안에서 변형을
   언급한다 (예: 割り出す+割り出せる → 1건, "드라마에서는 가능형으로 나왔어요").
3. 파일명 **순번 접두**: `N. 単語.mp3` — 번호는 피커 목록 순서(=드라마 등장 순서)로 1부터 연속.
4. 배치 전에 ElevenLabs 잔여 크레딧 확인:
   `GET https://api.elevenlabs.io/v1/user/subscription` (헤더 xi-api-key). 대본당 약 500자.
   부족하면 사용자에게 보고 후 중단.

## 단어정리 txt 양식 (스마트 글라스용)

word-tts 스킬의 "스마트 글라스용 단어 정리 txt"와 동일. 번호는 mp3 번호와 일치, **번호 사이 빈 줄 하나**:

```
1. 開廷 (かいてい)
개정 — 재판을 시작함
開 열 개 / 廷 조정 정

2. つまずく
발이 걸려 넘어질 뻔하다; (일이) 틀어지다
(한자 없음 · 가나)
```

가나 단어는 `(한자 없음 · 가나)`, 외래어는 `(한자 없음 · 외래어)`.

## _tts단어장.csv (누적 단어장)

- 위치: **볼트** `{vault_root}\15. Training\15.10. 일본어\_tts단어장.csv`, UTF-8 BOM
  — 경로는 `_config\vocab_db.py`가 `local-paths.md`의 `vault_root`로 계산한다(하드코딩 금지).
  볼트는 집·회사 PC가 동기화되므로 **드라마·Tiro 회의·Primetals 단어가 한 파일**로 모인다.
- 스키마: `단어,읽기,뜻,생성일,출처,mp3파일명`
- build_picker.py가 읽어 이미 만든 단어를 회색·선택불가 처리 → 화가 거듭될수록 중복 없음

## 산출물 구조 (쿠조1 검증 기준)

```
{화 폴더}\
├── 단어피커_{제목}.html          ← 1단계
├── _word_lines.json              ← 3단계 (중간 산출물)
├── TTS\
│   ├── 1. 開廷.mp3 … N. ○○.mp3   ← 5단계
│   ├── {제목}_단어정리.txt        ← 6단계 (글라스: 단어 MP3용)
│   └── 대본\ (N. ○○_대본.txt / _대본tts.txt)
└── lln_anki_items_*\media\
    ├── 1_～.mp3 … 71_～.mp3      ← anki-mp3-rename 산출물 (문장 MP3)
    └── {제목}_대사단어_글라스.txt ← 8단계에서 이동 (글라스: 문장 MP3용, jpg는 삭제)
```
