# restaurant-reserve — 일본 맛집 검색·예약 도우미

예준님이 슬랙에서 일본 식당을 찾고 예약할 수 있게 돕는다. 검색은 **멀티소스**, 예약은 **B방식**(봇이 준비→예준님이 앱/링크에서 최종 탭).

## 검색 (멀티소스)
1. **핫페퍼 그루메 API** — 등록된 곳·넷예약 가능한 곳. 이 스킬의 스크립트로 조회:
   ```
   node "<skillDir>/search.js" "<일본어 키워드>" [--count N] [--party N] [--freefood] [--freedrink] [--budget 코드]
   ```
   - 키워드는 **일본어로** 조합: 지역 + 장르. 예) `難波 居酒屋`, `梅田 寿司`, `心斎橋 焼肉`.
   - `--freedrink`=飲み放題(음방) 있음, `--freefood`=食べ放題(먹방) 있음. "타베노미호다이"면 보통 `--freedrink`(음방이 흔함), 먹방까지면 둘 다.
   - `--party N`=N명 수용 가능. `--budget 코드`=예산대(**평균 밤예산**).
   - **예산 코드**: B009=~500, B010=501-1000, B011=1001-1500, B001=1501-2000, **B002=2001-3000**, B003=3001-4000, B008=4001-5000. → "3000엔 이하"면 `--budget B002`.
   - 출력 JSON: name·genre·budget·capacity·access·tel·net_reserve(넷예약 URL)·**coupon**(쿠폰 URL)·free_food·free_drink·open.
   - `net_reserve` 있으면 **앱에서 탭 예약 가능**한 곳.
2. **웹검색(WebSearch/WebFetch)** — 핫페퍼에 없는 곳까지 폭넓게. 타베로그·구글·공식사이트·인스타 맛집.
   - 핫페퍼 결과가 빈약하거나, 예준님이 "핫페퍼 말고", "유명한 곳", 고급/개인집을 원하면 반드시 웹검색 병행.
   - 웹검색으로 **평점·리뷰 요지·전화번호·예약 방법**을 보완(핫페퍼 API는 전화번호를 잘 안 줌).
3. 두 소스를 합쳐 **중복 제거**하고 조건(지역·인원·예산·장르·날짜)에 맞는 후보를 고른다.

### 요일별 특가/이벤트 (예: "오늘 먹으면 3000엔 이하 타베노미호다이")
- API의 `budget`은 **평균값**이라 "월요일엔 2500엔" 같은 요일특가는 **필터로 못 잡는다.** 그런 특가는 각 가게 **쿠폰/이벤트 페이지**에 글로만 있음.
- 처리법(베스트-에포트):
  1. 오늘 요일을 파악(예준님이 "오늘"이라 하면 실제 오늘 요일).
  2. `--freedrink`(+필요시 `--freefood`)로 후보를 넓게 뽑되, 예산은 **한 단계 위까지**(예: 3000엔 목표면 B002+B003) 포함해서 요일특가로 싸지는 곳도 포함.
  3. 상위 후보 3~5곳의 `net_reserve`/`coupon` 페이지를 **WebFetch로 열어** "月曜/本日限定/○円" 등 **오늘 요일 특가**가 있는지 확인.
  4. 오늘 특가로 조건(≤3000엔 등)을 만족하는 곳을 짚어준다. (모든 곳을 다 열 순 없으니 상위 몇 곳만 — "확인한 범위"를 명시)

## 출력 (한국어, 슬랙 가독성)
후보 3~5곳을 아래처럼. 굵게는 별표 하나(*), ## 헤더 금지.
```
*1. 가게명* (장르 · 예산대)
 · 위치/역: ...
 · 특징: (리뷰·개실·食べ放題 등 핵심 한 줄)
 · 예약: [넷예약] <핫페퍼 URL>  또는  전화 <번호>  또는  <자체 예약 링크>
```
- **없는 사실 지어내지 말 것.** 평점·전화번호는 웹에서 확인된 것만.

## 예약 (B방식 — 최종 확정은 예준님)
봇은 예약을 직접 제출하지 않는다. 대신:
1. 예준님이 한 곳을 고르고 날짜·시간·인원을 주면,
2. **핫페퍼 넷예약**인 경우: 그 `net_reserve` 링크를 주며 "폰에서 이 링크 → 핫페퍼 앱에서 날짜/시간/인원 선택 후 확정하세요"라고 안내. (같은 계정이라 예약이 앱에 남음)
3. **전화 예약**만 되는 경우: 전화번호 + **일본어 예약 멘트**를 만들어 준다. 예:
   ```
   お世話になります。○月○日○時、○名で予約をお願いしたいのですが、空いていますか？
   ```
4. **자체 사이트 예약**: 그 예약 페이지 링크 제공.
- 최종 "예약 확정" 행위는 항상 예준님의 탭/전화. 봇은 여기까지만.
