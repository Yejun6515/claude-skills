# Meeting Time Grid

날짜 목록과 참석자 이름 목록을 받아, **회의 시간 조율용 가용시간 그리드** 한 장짜리
Excel(.xlsx)을 만든다. 회사 표준 양식(`reference/example_260511_POSCO_P2H.xlsx`)을
그대로 재현한 빈 표로, 각 셀은 참석자가 나중에 ○/× 로 채운다.

레이아웃:

- **A열** — 날짜 라벨(예 `5/26(Tue)`), 하루당 시간대 개수만큼 세로 병합.
- **B열** — 시간대 `09:00~10:00` … `16:00~17:00`, 중간에 `Lunch` 행(노란 음영).
- **C열 이후** — 참석자 한 명당 한 열, 헤더는 이름 그대로. 본문 셀은 비워 둠(손으로 표시).

## 입력 (사용자가 주는 것)

1. **날짜** — 하나 이상. "5/26, 5/27" / "다음주 화·수" / "2026-05-26" 등 어떤 형태든
   ISO(`YYYY-MM-DD`)로 정규화한다. 연도가 없으면 문맥(폴더명·오늘 날짜)에서 추론하고,
   애매하면 물어본다. **요일은 직접 계산하지 말 것** — 스크립트가 ISO에서 계산한다.
2. **참석자 이름** — 쉼표/줄바꿈으로 구분된 목록. 준 형식 그대로 열 헤더로 쓴다
   (예 `Kuroda, Akio`, `Kim, Yejun`). 순서도 준 순서 유지.

시간대는 기본값(09:00~17:00 매시간 + Lunch)을 쓰되, 사용자가 다른 범위/슬롯을
지정하면 `time_slots`로 넘긴다.

## Workflow

1. **날짜·사람 파싱.** 날짜를 ISO 리스트로, 이름을 순서 있는 리스트로 정리.
2. **`data.json` 작성** (아래 형식) — 출력 폴더 옆(또는 스크래치패드)에.
3. **실행:** `python scripts/generate_meeting_grid.py <data.json> <output.xlsx>`
   (Python 3 + `openpyxl` 필요. 없으면 `python -m pip install openpyxl`.)
4. **저장 위치.** 사용자가 프로젝트/회의 준비 폴더를 지정했으면 거기에 저장. 없으면
   물어보고, 기본값은 바탕화면(`%USERPROFILE%\Desktop`). 파일명은 첫 회의 날짜를 앞에 붙여
   `<YYMMDD>_<제목> meeting.xlsx` (제목 없으면 `<YYMMDD>_meeting availability.xlsx`),
   참조 양식 파일명 규칙(`260511_POSCO P2H mid review online meeting.xlsx`)을 따른다.
5. **리뷰.** 파싱한 날짜(요일 포함)·참석자 목록·저장 경로를 보여주고, 판단한 부분
   (추론한 연도, 요일, 저장 위치 등)을 밝혀 사용자가 고칠 수 있게 한다. 필요하면 재실행.

## 데이터 형식 (`data.json`)

```json
{
  "dates":  ["2026-05-26", "2026-05-27"],
  "people": ["Kuroda, Akio", "Abe, Hironori", "Sako, Akira", "Kim, Yejun"],
  "time_slots": ["09:00~10:00", "10:00~11:00", "11:00~12:00", "Lunch",
                 "13:00~14:00", "14:00~15:00", "15:00~16:00", "16:00~17:00"],
  "lunch_label": "Lunch"
}
```

- `dates` — ISO `YYYY-MM-DD` 리스트. 스크립트가 `M/D(요일)` 라벨과 요일을 계산.
- `people` — 열 헤더로 그대로 들어감(형식·순서 보존).
- `time_slots` — **선택.** 생략하면 위 기본 8슬롯. 날짜마다 이 슬롯이 반복된다.
- `lunch_label` — **선택**(기본 `"Lunch"`). 이 값과 같은 슬롯 행은 노란 음영 처리.

## How it's built

`scripts/generate_meeting_grid.py`가 openpyxl로 그리드를 처음부터 만든다(날짜·사람 수가
매번 달라지므로 템플릿 복사가 아니라 생성 방식). 얇은 테두리 전면 적용, 날짜/시간 라벨은
Malgun Gothic·가운데 정렬, 날짜열 블록 병합, Lunch 행 노란(`FFFF00`) 음영, 열 너비
(A=12.5 / B=20.5 / 사람열=15.75)까지 표준 양식과 동일하게 맞춘다.
