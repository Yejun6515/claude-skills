# meeting-report-mail — 사내 출장·회의 보고 메일 (한국어 전용)

고객 방문/미팅 결과를 PTJ 사내(엔지니어·상사)에 보고하는 메일 초안을 만든다.
소스는 해당 회의의 옵시디언 회의록 노트(`# 티대리 정리`) 또는 Tiro 요약.

## 대원칙 (예준님 확정 2026-07-17)
- **한국어로만 작성한다. 일본어 버전을 만들지 않는다** — 번역은 예준님이 직접 함.
- 단, **양식 헤더 라벨은 일본어 그대로**: `日時・場所` / `出席者` / `協議内容` (사내 통용 서식).
- 회의 여러 건이면 **한 건씩** 초안 → 확인 → 다음 건 진행 (한꺼번에 다 쏟지 않기).
- 사내 메일이므로 **인사말 생략**, 첫 줄부터 본론.

## 고정 양식 (2026-07-17 K3C 최종 발송본으로 확정)

```
제목(안): POSCO 출장보고 (<안건 요지>) M/D

各位

<리드 문장 1줄 — 방문일+안건 보고. 신규 요구·긴급 기한이 있으면 여기서 볼드로 먼저>

1. 日時・場所
・2026年7月16日(木) 14:00~15:00 / POSCO浦項本社

2. 出席者
・POSCO: Investment Engineering Office Kim Sangwoo PM、Choi Wonsik様
・WNC: Lim Donggyun
・PTJ: Kim Yejun

3. 協議内容

(1) <소제목>
- 개조식 bullet (~함/~임 종결 또는 명사 종결)
- 핵심 수치·결정사항은 **볼드**
- 문답이 있었던 안건은 화살표 대화체로 재현:
  •  <우리가 던진 질문/안건>? → POSCO: <답변> → PTJ: <우리 회답·약속>

(2) <소제목>
...

4. Follow-up
- POSCO: <내용>(기한) / <내용>(기한)
- PTJ: <내용>(기한)

잘 부탁드립니다.
김예준
```

## 작성 규칙
- **첫 줄은 `各位`** (사내 일제 배포 인사), 그다음 리드 문장.
- **出席者 표기**: 회사별로 `・회사명:` 줄 분리. 고객은 `부서 영문명 + 성명 + 직책`(직책 있으면 様 생략 가능: `Kim Sangwoo PM`), 직책 없으면 `様`. 대리점(WNC 등)은 様 없이 성명만. **당사는 반드시 `PTJ: Kim Yejun`** (Yejun Kim 금지 — 예준님 확정 26-07-17).
  - 예시(예준님 발송 원형): `・POSCO: Investment Engineering Office Kim Sangwoo PM、Choi Wonsik様 ・WNC: Lim Donggyun ・PTJ: Kim Yejun` / `・PSC: Yu GangSig様、Kim Yongnam様 ・JPS: Takashina様 ・Sojitz: Takahashi様`
- **문답 왕복은 화살표 대화체**로 살린다: `→ POSCO: 전혀 파악하지 못하고 있음 → PTJ: 승지, 투자요청 올라오면 공유 부탁`. 요약으로 뭉개지 말고 누가 뭐라 답했는지 보이게.
- **뉘앙스·사내 사정도 명기**: 상대 인물평("새 Group장이 매우 꼼꼼한 성격"), 실무진 분위기("실무진도 곤혹"), 당사 해석("형식적 보고라 계약 일정에 큰 영향 없을 것") 등 영업 맥락을 능동적으로 얹는다 — 사내 보고의 가치.
- **맺음은 "잘 부탁드립니다. 김예준"** (예준님 번역 시 何卒よろしくお願いいたします。キム).
- **참석자를 모르면 지어내지 않는다** — `[성함 기입]様`로 자리만 잡고 보고에서 기입 필요를 surface (loa-surface-conservatively 원칙).
- 일시는 Tiro 녹음 시간 기준이면 "~시경" + 확인 필요 표시. 장소 추정이면 확인 요청.
- **協議内容**: (1)(2)(3) 소제목 + 개조식. 회의 흐름이 아니라 **중요도 순**(합의·결정 → 신규 요구 → 일정 → 기타).
- **사내 보고에는 민감 정보를 명기한다** — 가격 인하 요청, 경쟁사 동향, 고객 내부 사정(맨파워 부족 등). 고객 발송용과 반대.
- 미확인 전사 용어(오인식 의심 고유명사)는 메일에 그대로 쓰지 말고 일반화("경쟁사", "선행 건")하거나 🟡로 표시.
- 당사에 대한 의뢰(엔지니어 검토 요청 등)는 Follow-up 또는 본문에서 **"~부탁드리고자 함"**으로 명시.
- 일정 마일스톤이 많으면 화살표 한 줄로 압축: `견적 8/20~21 → 투심위 9월 → 경영위 11/2 → 계약 2027년 2~3월`.
- To/CC는 해당 프로젝트 직전 스레드 참가자 기준으로 **제안**만 (라우팅 확정은 `메일 자동화\00_가이드\패턴.md`·mail-bridge 참조).

## 워크플로
1. 소스 확보 — 회의록 노트(`# 티대리 정리`) 또는 Tiro 요약 읽기.
2. 위 양식으로 초안 1건 작성 (여러 건이면 첫 건만).
3. 참석자·장소·일시 등 미확인 항목을 기입란 + 확인 목록으로 제시.
4. 예준님 확인·수정 후 다음 건 진행. (발송·번역은 예준님)

## 참고 — 실전 예 (2026-07-16 POSCO 3건)
K3C(투자심의 일정)·P2H(하우징+내하중 증강)·P3PL(Case-3 능력증강) 보고 3건이 이 양식의 원형.
- 리드 문장에 긴급성 명시 예: "**신규 요구(내하중 증강)가 발생**했으며, 7/17 자료 제출이 당면 기한입니다."
- 제목 예: `POSCO 출장보고 (P2H 하우징 갱신·내하중 증강 신규 요구) 7/16`
